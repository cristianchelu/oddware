# @oddware/zigbee.cat-toy

One controller board for three battery-powered Zigbee cat toys: a flapping
bird, a flapping fish and a rolling ball. The board drives a motor and a
speaker, wakes on motion, charges over USB-C, and joins Home Assistant as a
sleepy Zigbee end device. The toys differ only in what is plugged into its
three JST-PH connectors.

![Rev A board, KiCad 3D render](docs/pcb_rev_a_iso.png)

> This one is vibe coded: AI agents did most of the work, with me steering.
> It has never been built. There is no expectation that it works or will be
> finished; it's a side project parked here.

## Status

- **Rev A** (this tree) — nRF52840 in an Ebyte E73 module. Designed and
  DRC-clean, never built. The E73 and the LIS2DH12 are "Standard only" parts
  at JLC, which put 5 assembled boards at about $200 landed. Cancelled.
- **Rev B** — moves to an ESP32-C6 module, with every part eligible for JLC
  Economic PCBA. In progress.
- No firmware yet.

## The toys

| Toy | Motor | Battery | Speaker |
|-----|-------|---------|---------|
| Flappy bird | N20 gearmotor, 6 V winding, 300–400 rpm | 1S LiPo pouch, ~500 mAh | yes |
| Flappy fish | same as bird | same as bird | no |
| Rolling ball | N20 gearmotor, 6 V winding, ~100 rpm | 803040, 1000 mAh | no |

- Any 3.7 V cell with a JST-PH lead works, protected or not. The board has
  its own protection and a reverse-polarity FET; JST-PH pigtails come wired
  both ways.
- Keep the ceramic capacitor across the motor tabs. It suppresses brush noise
  next to a 2.4 GHz radio.

## The board

40 × 26 mm, 2 layers, every assembled part on top.

| Block | Part | Notes |
|-------|------|-------|
| MCU + radio | Ebyte E73-2G4M08S1C (nRF52840) | Runs straight off the cell through VDDH; no regulator. Native USB on the charging port |
| Motor driver | TI DRV8213 | Current sense on IPROPI, no shunt. Firmware picks the hardware current limit per toy: 1.66 A, 324 mA or 69 mA |
| Accelerometer | ST LIS2DH12 | Wake-on-motion and tap |
| Charger | TP4054 | 300 mA from USB-C; red LED while charging |
| Cell protection | XySemi XB5353A | Low side, FETs built in |
| Reverse polarity | AO3401A | High side |
| Speaker | AO3400A | Low-side PWM switch; plays 8-bit samples |

- Left edge — motor, speaker and battery JST-PH connectors.
- Right edge — USB-C, status and charge LEDs, side-push pairing button.
- Top edge — the module antenna, overhanging the board by 2.8 mm.
- Back — SWD header (unpopulated), debug UART pads, 20 labelled test pads.

Schematic: [PDF](hardware/zigbee_toy/zigbee_toy_schematic.pdf). Pin map,
power budget, per-block circuits and layout notes:
[docs/hardware-design.md](docs/hardware-design.md).

## Rebuilding

The schematic and the board are generated by scripts. Do not edit them in
KiCad; the next build overwrites the changes.

| To change | Edit |
|-----------|------|
| Parts and nets | `hardware/tools/design.py` |
| Board placement | `hardware/tools/placement.py` |
| Copper | `hardware/tools/routes.py` (hand routes), `routes_frozen.py` (a frozen Freerouting pass) |
| Silkscreen | `hardware/tools/silk.py` |

Needs the KiCad 10 flatpak, ImageMagick, and network access the
first time a new LCSC number shows up in the BOM.

1. Run `hardware/tools/build.sh`. It writes the schematic, runs ERC, checks
   the netlist against intent, and writes the PDF and the JLC BOM.
2. Run `hardware/tools/pcb_build.sh`. It places, routes, stitches, adds the
   silkscreen and runs DRC.
3. Run `hardware/tools/export_jlc.sh`. It writes `gerbers.zip`, `cpl.csv`
   and `bom.csv` to `hardware/zigbee_toy/build/jlc/`.

Outputs go to `build/` folders, which git ignores.

## Ordering notes

- JLC places a part using the origin and rotation of *its* EasyEDA
  footprint, not KiCad's. A raw KiCad position file puts the SOT-23s and the
  LIS2DH12 90–180° off, and the USB-C and E73 1.6–2 mm off their pads. `jlc_cpl.py` fits each
  KiCad footprint onto the EasyEDA one and corrects the CPL; it fails if a
  fit is poor. Check JLC's 3D placement preview anyway.
- The EasyEDA footprints are cached in `hardware/tools/easyeda/`. The
  export script downloads only missing ones.
- The USB-C overhangs the board edge by 1 mm and the antenna by 2.8 mm. Ask
  for tab routing in the order remark, not V-cuts.
- Check each part's "PCBA Type" on its JLC page. One "Standard only" part
  moves the whole order to Standard PCBA.
